# hf-core-utils

Utility libraries for the HardFOC stack, collected as Git submodules and
consumed by [hf-core](https://github.com/hardfoc/hf-core):

| Submodule | Contents |
|-----------|----------|
| [hf-utils-general](https://github.com/hardfoc/hf-utils-general) | Header-only C++17 helpers: PID, filters, curve fitting, buffers, variable monitors, CRC |
| [hf-utils-rtos-wrap](https://github.com/hardfoc/hf-utils-rtos-wrap) | C++ wrappers over FreeRTOS primitives |
| [hf-utils-canopen](https://github.com/hardfoc/hf-utils-canopen) | CANopen NMT/SDO frame builders and CiA 402 helpers |
